# Bank Transfer Transaction

## Description
This project demonstrates a bank transfer using Python and PostgreSQL.

## Concepts Used
- PostgreSQL database connection
- Python context manager
- Transactions
- COMMIT and ROLLBACK
- Exception handling
- Insufficient balance validation

## Test Results
- Transferred 2000 from Arun to Priya
- Forced an error after debit and verified rollback
- Rejected transfer when balance was insufficient

## Final Balances
- Arun: 8000
- Priya: 7000

## Tools
- Python
- PostgreSQL
- pgAdmin
- VS Code
